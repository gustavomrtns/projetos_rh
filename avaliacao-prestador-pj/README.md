# Avaliação de Prestadores de Serviço — PJ

## Contexto

A gestão de prestadores exige critérios claros para avaliar qualidade, aderência contratual, custo-benefício e impacto do serviço entregue.

## Problema

Sem uma estrutura padronizada, avaliações de fornecedores podem se tornar subjetivas e pouco úteis para governança e decisões futuras.

## Minha atuação

- Estruturação dos critérios de avaliação.
- Organização da lógica de classificação e impacto.
- Desenvolvimento do formulário digital.
- Estruturação das informações para apoiar governança e acompanhamento.

## Solução

Ferramenta digital para avaliação de prestadores de serviço por critérios contratuais, qualidade, custo-benefício e impacto.

## Tecnologias e abordagens

HTML · CSS · JavaScript · Governança · Gestão de Fornecedores · Avaliação

## Impacto esperado

- Critérios mais objetivos de avaliação.
- Registro padronizado do desempenho do prestador.
- Melhor rastreabilidade para futuras contratações.
- Apoio à governança e à gestão contratual.

## Competências demonstradas

Governança · Gestão de Fornecedores · Processos · Avaliação · Tomada de Decisão
