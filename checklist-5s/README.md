# Checklist 5S

[▶ Abrir aplicação](https://gustavomrtns.github.io/projetos_rh/checklist-5s/) · [← Voltar ao portfólio](../README.md)

## Contexto

Auditorias 5S exigem critérios consistentes, registro organizado e leitura clara dos resultados para apoiar melhoria contínua.

## Problema

Controles manuais dificultam padronização, comparação entre avaliações e visualização de pontos críticos.

## Minha atuação

- Estruturação de critérios de auditoria.
- Organização da lógica de pontuação e conformidade.
- Desenvolvimento da aplicação digital.
- Estruturação dos resultados para facilitar leitura e acompanhamento.

## Solução

Checklist digital para auditoria 5S, com critérios de avaliação, indicadores de conformidade e organização dos resultados.

## Tecnologias e abordagens

HTML · CSS · JavaScript · 5S · Indicadores · Melhoria Contínua

## Impacto esperado

- Padronização das auditorias.
- Maior rastreabilidade dos resultados.
- Identificação mais rápida de desvios.
- Apoio a planos de melhoria contínua.

## Competências demonstradas

5S · Processos · Qualidade · Indicadores · Melhoria Contínua
