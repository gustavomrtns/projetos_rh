Base de dados

Todos os planos de ação enviados ficam salvos no armazenamento deste navegador (visível em qualquer aba deste mesmo navegador, mas não em outros computadores ou navegadores). Use o botão abaixo apenas se quiser reiniciar completamente os dados de demonstração.

Sobre este ambiente

Este é um protótipo funcional que roda inteiramente no navegador. Não há backend, autenticação real, banco de dados relacional ou integração com Excel/SQL em produção — os dados ficam salvos apenas no armazenamento local deste navegador, o que significa que um plano enviado em um computador não aparece automaticamente em outro. Para uso corporativo real (login de gestores e do Painel Gerencial, permissões verificadas no servidor, base de dados única acessível de qualquer lugar), é necessário desenvolver um backend dedicado.
